# [Stock Alert Dashboard](https://npmisantosh.github.io/stocks)

A trading dashboard for monitoring positions, performance metrics, and trade history.

## Features

- Dashboard with key performance indicators (total trades, win rate, avg return, etc.)
- Open positions table with expandable price charts
- Closed trades history with sorting and filtering
- Performance page with return distribution chart and monthly summaries
- Today's trading signals

## Built with

- React 18 + TypeScript
- Vite 5
- Tailwind CSS 3
- Recharts
- React Router v6

## Development

```bash
npm install
npm run dev     # start dev server
npm run build   # build for production
```

Deployed via GitHub Actions on push to `main`.
